K-Zone

Windows 창 분할 레이아웃 매니저

창을 드래그해서 존에 스냅시키면
그 자리에 딱 맞게 배치된다.
멀티모니터마다 독립된 레이아웃,
그리드 편집기로 내 화면에 맞춰 직접 나눈 구역까지 —
조용히 트레이에 상주하는 창 관리 프로그램.

현재 버전v1.2.5
배포일2026-09-11
지원 환경Windows 10 · 11 64bit
01

다운로드

Windows 64bit
설치형 다운로드 K-Zone.Setup.1.2.5.exe 포터블 다운로드 K-Zone.exe

설치형 자동 업데이트

트레이 우클릭 → 프로그램 정보 → 업데이트 확인으로 새 버전을 바로 받을 수 있습니다. 이 페이지에 다시 올 필요가 없습니다.

포터블 수동 갱신

자동 업데이트가 지원되지 않습니다. 새 버전이 나올 때마다 이 페이지에서 파일을 다시 받아야 합니다.

02

이번 버전

v1.2.5 2026-09-11

레이아웃 삭제 확인창 추가, 우클릭 메뉴 디자인 통일, 앱 전체 말투 존댓말로 통일, 종료 원인 기록 추가

  • 레이아웃을 우클릭해서 지울 때 확인창이 뜨도록 변경(전에는 묻지 않고 바로 지워졌음)
  • 기본 레이아웃은 지워도 다음 실행 때 다시 나타난다는 사실을 확인창에서 알려줌
  • 우클릭 메뉴를 확인창과 같은 디자인으로 통일
  • 앱 안의 모든 문구를 존댓말로 통일
  • 프로그램이 예상치 못하게 종료될 때 원인을 기록하도록 추가
  • 옛 이름으로 등록된 시작프로그램 잔재 제거
03

설치 방법

약 1분
STEP 1

설치형 다운로드 클릭
내려받은 exe 파일을 실행합니다.

STEP 2

Windows 보호 경고
“추가 정보” → “그래도 실행”을 누릅니다.

STEP 3

.NET 8 자동 안내
없으면 설치 안내가 자동으로 뜹니다.

STEP 4

트레이에서 실행 확인
설치가 끝나면 트레이에 상주하며 바로 동작합니다.

아무 창이나 항상 위에 고정·해제

트레이 상주 · 자동 시작

백그라운드에서 조용히 대기

프로그램 정보에서 업데이트 확인 클릭 한 번

프로그램 정보 다이얼로그

버전·업데이트 확인을 한 창에서

05

필독 사항

설치 전 확인

설치·실행 전에 아래 세 가지만 알아두면 막힘없이 바로 쓸 수 있습니다.

.NET 8 Runtime 필요

K-Zone 실행에는 .NET 8 Runtime(x64)이 필요합니다. 설치돼있지 않으면 실행 시 자동으로 설치 안내가 뜹니다.

Windows 보안 경고

exe 실행 시 SmartScreen 경고가 뜰 수 있습니다. “추가 정보” → “그래도 실행”을 누르면 정상적으로 실행됩니다.

이미 설치돼 있다면

설치형을 다시 실행하면 먼저 제거 여부를 확인한 뒤 진행됩니다. 관리자 권한으로 켜놓은 상태에서도 재설치가 안정적으로 됩니다.
